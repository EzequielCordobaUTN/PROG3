Trabajo Práctico – Callbacks, Promesas y Async/Await

Los resultados se muestran abajo y en la consola del navegador (esperar ~1.5s).




  Callback = se pasa una función como argumento que se ejecuta después de un tiempo.

  Promesa = objeto que representa un resultado futuro (resolve/reject).

  Async/Await = forma más limpia de escribir código asíncrono usando promesas, con try/catch para errores.
