Lista de tareas

Aplicación interactiva del Trabajo Práctico: funciones, objetos, desestructuración, spread/rest, DOM y eventos.

Punto 1 – Funciones declarativas y expresadas

Explicación: una función declarativa se define con la palabra clave function y se "hoistea" (se puede usar antes de su declaración). Una función expresada se asigna a una variable; no se hoistea y solo existe después de esa línea. Se usan declarativas para funciones generales/reutilizables y expresadas cuando se quiere tratar la función como valor (callbacks, asignaciones condicionales).

Punto 2 – Arrow function con parámetro por defecto

Explicación: la arrow function (nombre, edad = 18) usa un parámetro por defecto, por eso si no se pasa la edad toma 18. Las arrow functions tienen sintaxis más corta y no tienen su propio this.

Punto 3 – Objeto persona

Explicación: las propiedades guardan datos (nombre, edad) y los métodos son funciones asociadas al objeto que operan sobre esos datos (presentar). Propiedades = estado/valores; métodos = comportamiento/acciones.

Punto 4 – Desestructuración

Explicación: la desestructuración permite extraer propiedades del objeto en variables con una sola línea, haciendo el código más limpio y legible que acceder a cada persona.nombre, etc. También evita repetición y es útil en parámetros de funciones.

Punto 5 – Operador spread y rest

Explicación: spread (...) "expande" un iterable en elementos sueltos (copiar/combinar arrays). rest (...) en parámetros de función "agrupa" los argumentos restantes en un array. Mismo símbolo, uso opuesto según el contexto.

Punto 8 – Evento submit y preventDefault

preventDefault() evita el comportamiento por defecto del envío del formulario (recargar la página), permitiendo manejar los datos con JavaScript.
